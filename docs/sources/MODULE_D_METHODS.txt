Modification measures
English word regex: [A-Za-z]+(?:['’\-][A-Za-z]+)*. Words are lowercased for edit distance. Token insertion, deletion and substitution each cost 1. The Myers bit-vector implementation computes exact Levenshtein distance; tests compare 250 random cases with a separate dynamic-programming reference. Normalized distance = distance / max(original words, edited words, 1). Length ratio = edited words / original words. These word sequences omit punctuation and numbers; separate checks track numeric changes.

Automatic review triggers
Length ratio outside [0.5, 1.5]; changes in multisets of numeric expressions, supported date formats, bracketed numeric citations or URLs, and candidate proper names. Candidate names comprise consecutive capitalized words or uppercase acronyms. Date formats include numeric dates and full English month names followed by a day. Regex definitions are in src/edits/analyze.py. These triggers can include harmless reformulations and capitalization differences. Reviewers assess actual content changes by reading each pair.

Detector analysis
Use the frozen B and C pipelines selected in their validation experiments, with threshold 0.5. Model B is TF-IDF plus logistic regression. Model C is the full 32-feature random forest, including POS features. The bundle includes both frozen models and C's runtime feature code and POS resource. Module D performs inference on 2,095 distinct validation texts. Shared original texts are scored once and mapped back to their pairs.
Detection rate = count(score >= 0.5) / pair count. Score change = edited score - original score. AI-to-human flip means original score >= 0.5 and edited score < 0.5. Two flip fractions use all pairs and detected originals as separate denominators. Human-to-AI reversals are also recorded.
